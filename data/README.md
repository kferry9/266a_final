# Data

Data for the 266A final project on DMS structure probing of *in vitro* transcribed human telomerase RNA (hTR).

## Folders

| Folder | Contents | Edited by |
|--------|----------|-----------|
| `data/raw/` | Original data as received | Nobody. Never edit. |
| `data/processed/` | Cleaned data written by `run-analysis.qmd` | The pipeline |

Anything in `data/processed/` can be deleted and regenerated by re-rendering `run-analysis.qmd`.

## How the data were generated

hTR was treated with dimethyl sulfate (DMS), which modifies unpaired bases. During reverse transcription, modified bases cause mismatches, which are mapped by Illumina short-read sequencing. Mutation counts at each nucleotide position therefore reflect how accessible that position was to DMS.

Samples are two replicates (`hTR_DMS_1`, `hTR_DMS_2`), each with a DMS-treated (`DMS_plus`) and an untreated (`DMS_minus`) condition.

## Raw file

`data/raw/266_seq_data.csv`

| Column | Description |
|--------|-------------|
| `sample` | Replicate: `hTR_DMS_1` or `hTR_DMS_2` |
| `probe` | Condition: `DMS_plus` (treated) or `DMS_minus` (untreated) |
| `nucleotide` | TODO: describe (position or base identity) |

- **Source:** Experimental data (collected by the author)

## Processed file

`data/processed/seq_clean.csv`

Created in Step 1 of `run-analysis.qmd`. Same columns as the raw file, with these changes:

- Read depths (`raw_read_depth`, `effective_depth`) that were 0 or negative are set to `NA`. A mutation rate is mutations divided by read depth, so depth cannot be zero.
- `raw_read_depth` is converted to numeric.

Rows are not removed at this stage. Rows with `NA` are dropped later by model fitting (`lm()`), so check `nobs()` against `nrow()` when modelling.

## Columns added during analysis

These are created in memory in Step 2 and are not saved to the CSV:

| Column | Formula |
|--------|---------|
| `raw_mut_rate` | `mutations / raw_read_depth` |
| `effective_mut_rate` | `mutations / effective_depth` |

## Notes

- Do not open and re-save the raw CSV in a spreadsheet program, which can change formatting and values.
- If a path error occurs when reading data, check that `data/processed/` exists before writing to it.
